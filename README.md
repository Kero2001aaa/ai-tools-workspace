# AI Tools Workspace

A cloud-first, cost-conscious foundation for building an external AI agent workspace.

## Included

- GitHub Codespaces development container
- Python 3.12, Node.js 22, and Docker tooling
- Lightweight LangGraph + MCP client dependencies
- Safe environment-variable template and secret exclusions
- Setup guide with a staged integration plan

## Start

Open the repository, then select **Code → Codespaces → Create codespace on main**:

https://github.com/Kero2001aaa/ai-tools-workspace

See [docs/SETUP.md](docs/SETUP.md) for verification, credential handling, and the integration roadmap.

## Important limitations

This project adds external tools and workflows; it cannot increase ChatGPT's native token quota, context window, or model capability. Hosted search and model APIs may require paid credentials. No API keys are included.
